# LLMClassificationFinetunning
This is my pre-solution for the kaggle competition [LLM Classification Finetuning](https://www.kaggle.com/competitions/llm-classification-finetuning)

Competition task is to indentify which generated responses are preferred for an user.

I have used:
- Pandas
- Pytorch
- HuggingFaceAPI
- GPT
- BERT
